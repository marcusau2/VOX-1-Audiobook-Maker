============================================
  VOX-1 Audiobook Maker - Quick Start
============================================

SYSTEM REQUIREMENTS:
  - Windows 10/11 64-bit
  - NVIDIA GPU with 8GB+ VRAM (12GB recommended)
  - Python 3.12
  - FFmpeg (for M4B output)

============================================
HOW TO LAUNCH:
============================================

  Double-click: RUN-VOX-1.bat

  Or from command line:
    python app.py

  Keep the console window open while using VOX-1!

============================================
BASIC WORKFLOW:
============================================

  1. THE LAB TAB — Create a voice
     - Voice Design: enter comma-separated attributes
       e.g. "male, moderate pitch, british accent"
     - Voice Clone: select a reference audio file
     - Click "Generate Preview", then "Save as Master Voice"

  2. BOOKSMITH TAB (optional) — Load EPUB/PDF
     - Select chapters to include
     - Edit text if needed
     - Click "Process & Send to Studio"

  3. STUDIO TAB — Render audiobook
     - Load Master Voice (if not already loaded)
     - Load book (.txt or .json manifest)
     - Click "Render Audiobook"

============================================
FIRST RUN:
============================================

  On first launch, the OmniVoice AI model (~3.5 GB)
  will download automatically. This only happens once.
